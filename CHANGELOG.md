# Changelog

## 0.1.0 — 2026-10-12

Initial public preview.

- Folder totals in Explorer's native Size column and mixed file/folder size sorting.
- Bounded asynchronous metadata scanning and directory-change invalidation.
- Classic context-menu enable/pause control, remembered per-user preference.
- Native COM loading with no separate background app or startup registration.
- Computer-wide installer/uninstaller with owned-file and registry checks.
- Exact-build symbol validation, complete source, tests, and release packaging.

Tested on Windows 11 25H2 build 26200.9550 x64 only. See VERIFICATION.md.
